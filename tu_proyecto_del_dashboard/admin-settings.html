Modo lectura

Parámetros de Nómina

Montos y porcentajes usados en la Liquidación de Choferes y en los cálculos de porcentaje mínimo garantizado.

Sueldo mínimo garantizado (RF-023, RF-036)

Este es el monto usado en "Liquidación por Chofer" para comparar el total ganado (RF-022) y determinar si se debe ingresar un "Monto Faltante" (RF-024).

Porcentaje por defecto de choferes (RF-007, RF-036)

Porcentaje base que se asignará automáticamente a todos los nuevos choferes registrados. Este valor se usa para calcular el "porcentaje ganado" (RF-015) cuando aún no se define un porcentaje individual.

Parámetros de Alertas y Vencimientos

Controla cuántos días antes se generan alertas visuales para documentación próxima a vencer.

Días de alerta para vencimientos (RF-031, RF-036)

El Dashboard mostrará alertas (RF-031) para documentación de máquinas y choferes cuya fecha de vencimiento (RF-007, RF-008) esté dentro de este número de días.
